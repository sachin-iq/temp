# Asset Drop Zone

Put any optional images or sounds for **Star Collector** in this folder.

Supported filenames (all optional):
- `player.png` – player sprite
- `enemy.png` – enemy sprite
- `star.png` – collectible sprite
- `collect.wav` – sound when picking up a star
- `hit.wav` – sound when hit by an enemy

If these files are missing, the game will automatically use simple colored shapes and will run without sound.
